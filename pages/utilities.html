Developer Utilities

A collection of small, focused tools for developers and power users — all running locally.

Hash Generator

Compute MD5, SHA-1, SHA-256, and SHA-512 hashes of any text using the Web Crypto API.

UUID Generator

Generate RFC 4122 version 4 UUIDs.

Base64 Encoder / Decoder

Encode text to Base64 or decode a Base64 string back to text. UTF-8 safe.

JSON Formatter

Format or minify JSON. Invalid JSON shows a clear error message.

Unit Converter

Convert between length, mass, temperature, area, volume, speed, and data units.

QR Code Generator

Generate a QR code from text or a URL. Download as PNG.

Currency Converter

Convert between 30+ currencies using the free Frankfurter API v2 (European Central Bank and other sources).

Exchange rates are fetched from frankfurter.dev (API v2). No API key is required. Rates are updated daily.
