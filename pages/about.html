About TrailKit

A unified browser toolkit inspired by seven open-source projects. Built as a static site with no backend.

Project Overview

TrailKit brings together useful functionality from seven GitHub repositories into a single, coherent web application. It is a static website — it requires no server, no build step, and no installation.

The tools are grouped into six categories: Outdoor & Navigation, Weather, Image & PDF, Audio & Speech, and Developer Utilities.

Privacy

TrailKit prioritizes local processing. Here is exactly what happens with your data:

  • Images & PDFs: Processed entirely in your browser using the Canvas API and jsPDF. Files are never uploaded to any server.
  • Speech: The Web Speech API is used. Depending on your browser, audio may be processed by the browser vendor's cloud service.
  • Weather: Your search query is sent to Open-Meteo's geocoding API.
  • Currency: Exchange rates are fetched from the Frankfurter API (ECB data).
  • Local storage: The theme preference and the last weather location are stored in your browser's localStorage.
  • No tracking: There are no analytics, cookies, or third-party tracking scripts.

Security

  • No shell command execution. No eval().
  • No secret API keys are included. All APIs used are free and public.
  • Uploaded files are handled locally.
  • External dependencies are limited to jsPDF (CDN) and qrcode-generator (CDN), both loaded over HTTPS.

Known Limitations

  • No native sensor access: Browsers cannot access phone barometers, magnetometers, or GPS with the same fidelity as a native Android app.
  • Speech recognition: The Web Speech API is not supported in Firefox.
  • Weather: Requires an internet connection.
  • Currency: Rates are updated daily by the ECB.
  • PDF generation: Very large images may consume significant memory.

External Dependencies

  • jsPDF (2.5.2) — PDF generation. Loaded from cdnjs.cloudflare.com. MIT License.
  • qrcode-generator (1.4.4) — QR code generation. Loaded from jsDelivr. MIT License.
  • Open-Meteo API — Free weather data. No key required.
  • Frankfurter API — Free currency exchange rates (ECB). No key required.
