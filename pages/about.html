About TrailKit

A unified browser toolkit inspired by seven open-source projects. Built as a static site with no backend.

Project Overview

TrailKit brings together useful functionality from seven GitHub repositories into a single, coherent web application. It is a static website — it requires no server, no build step, and no installation. Deploy it to GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static host.

The tools are grouped into six categories: Outdoor & Navigation, Weather, Image & PDF, Audio & Speech, and Developer Utilities. Each tool has its own dedicated interface with clear inputs, controls, outputs, and error handling.

Privacy

TrailKit prioritizes local processing. Here is exactly what happens with your data:

  • Images & PDFs: Processed entirely in your browser using the Canvas API and jsPDF. Files are never uploaded to any server.
  • Speech: The Web Speech API is used. Depending on your browser, audio may be processed by the browser vendor's cloud service (e.g., Google for Chrome). TrailKit does not receive or store audio.
  • Weather: Your search query is sent to Open-Meteo's geocoding API. Weather data is fetched directly from Open-Meteo. No API key is required.
  • Currency: Exchange rates are fetched from the Frankfurter API (ECB data). No personal data is sent.
  • Local storage: The theme preference and the last weather location are stored in your browser's localStorage. You can clear them at any time.
  • No tracking: There are no analytics, cookies, or third-party tracking scripts.

Security

  • No shell command execution. No eval().
  • No secret API keys are included. All APIs used are free and public.
  • Uploaded files are handled locally. File type and size are validated before processing.
  • External dependencies are limited to jsPDF (CDN) and qrcode-generator (CDN), both loaded over HTTPS.

Known Limitations

  • No native sensor access: Browsers cannot access phone barometers, magnetometers, or GPS with the same fidelity as a native Android app. The altitude estimator requires manual pressure input.
  • Speech recognition: The Web Speech API is not supported in Firefox. whisper.cpp WASM integration requires model files (75 MB–1.5 GB) and is not included by default.
  • Weather: Requires an internet connection. Open-Meteo is a third-party service.
  • Currency: Rates are updated daily by the ECB. Intra-day fluctuations are not reflected.
  • PDF generation: Very large images (many pages × high resolution) may consume significant memory. jsPDF converts images to JPEG internally, which may slightly reduce quality for transparent PNGs.

External Dependencies

  • jsPDF (2.5.2) — PDF generation. Loaded from cdnjs.cloudflare.com. MIT License.
  • qrcode-generator (1.4.4) — QR code generation. Loaded from jsDelivr. MIT License.
  • Open-Meteo API — Free weather data. No key required.
  • Frankfurter API — Free currency exchange rates (ECB). No key required.
