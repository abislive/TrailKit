About Browser Speech Recognition

How this tool works and what to expect:

  • Browser support: Chrome, Edge, and Safari support the Web Speech API. Firefox does not currently support live microphone transcription.
  • Processing: In many browsers, speech is processed by the browser vendor's cloud service (e.g., Google's servers for Chrome). This means audio may leave your device depending on your browser.
  • Privacy: TrailKit does not record, store, or transmit your audio. The Web Speech API is managed entirely by your browser.
  • Accuracy: Recognition quality depends on your microphone, background noise, and the browser's speech model.
  • Offline: Some browsers support offline speech recognition, but this is not guaranteed across all platforms.
whisper.cpp note: The reference repository whisper.cpp provides native/offline speech recognition. Running it in a browser requires WebAssembly (WASM) builds and model files (typically 75 MB–1.5 GB) that are not included here. This implementation uses the browser's built-in Web Speech API as a functional, zero-install alternative. See the About page for details on adding whisper.cpp WASM support in the future.
